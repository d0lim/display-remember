# Security policy

Security fixes target the latest public release. Reproduce issues on that version when practical.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/d0lim/display-remember/security/advisories/new). Do not post exploit details in public issues.

Include the affected version, macOS version, impact, and a minimal reproduction. Redact monitor identifiers, personal paths, and credentials. Please allow maintainers to investigate privately before publishing details.

The app invokes a bundled native display engine and uses private macOS APIs. Reports involving unexpected command execution, unsafe profile handling, or unintended disclosure of local data are relevant. Ordinary display compatibility problems can be reported as bugs after redacting identifying data.
